# آموزش ورود JSON مناسبت‌ها — Outtask

## دو روش ورود

### روش ۱: فرم ساده (برای اکثر کاربران) ✅ پیشنهادی
1. برو تب **تقویم**
2. سمت راست فرم **افزودن مناسبت** رو می‌بینی:
   - **عنوان**: مثلاً `تولد سارا`
   - **تاریخ**: یک date picker میلادی باز می‌شه — تاریخ میلادی رو انتخاب کن (مثلاً 1990-08-30)
   - **رنگ**: از color picker رنگ انتخاب کن
   - **تکرار سالانه**: اگر تولد یا سالگرده، تیک بزن
3. دکمه **افزودن مناسبت** رو بزن
4. مناسبت همون لحظه در تقویم میلادی (و جلالی کوچک زیرش) نمایش داده می‌شه

> این روش برای تولدها عالیه: تاریخ تولد واقعی رو بزن (مثلاً 1990-05-15) + تیک سالانه → هر سال ۱۵ می نشون داده می‌شه

---

### روش ۲: JSON حرفه‌ای (برای ورود گروهی)

#### کجا؟
- تب **تنظیمات** → کارت **ورود JSON مناسبت‌ها**
- یک textarea می‌بینی که داخلش آرایه JSON فعلی هست

#### فرمت دقیق
```json
[
  {
    "id": "optional",
    "date": "2026-08-30",
    "title": "تولد سارا",
    "color": "#e4f222",
    "repeat": "yearly",
    "type": "birthday"
  }
]
```

#### فیلدها
- `date` **الزامی**: میلادی `YYYY-MM-DD`
  - مثال: `2026-08-30` = 30 اوت 2026
  - برای تولد: تاریخ تولد اصلی رو بذار، مثل `1995-03-21`
- `title` **الزامی**: متن مناسبت
- `color` اختیاری: `#RRGGBB` مثل `#6366f1` — پیش‌فرض `#e4f222`
- `repeat` اختیاری: 
  - `"none"` = فقط همون روز دقیق
  - `"yearly"` = هر سال تکرار (برای تولدها) ← مهم
- `id` اختیاری: اگر نذاری خودکار ساخته می‌شه

#### مثال‌های آماده

**چند تولد سالانه:**
```json
[
  {"date":"1995-03-21","title":"تولد علی","color":"#ec4899","repeat":"yearly"},
  {"date":"2000-08-30","title":"تولد سارا","color":"#e4f222","repeat":"yearly"},
  {"date":"1992-12-10","title":"سالگرد ازدواج","color":"#6366f1","repeat":"yearly"}
]
```

**ترکیب تولد + جلسه کاری:**
```json
[
  {"date":"1990-05-15","title":"تولد مادر","color":"#eb5757","repeat":"yearly","type":"birthday"},
  {"date":"2026-09-01","title":"جلسه اسپرینت","color":"#02b8cc","repeat":"none","type":"meeting"},
  {"date":"2026-09-10","title":"ددلاین پروژه","color":"#e4f222","repeat":"none","type":"deadline"}
]
```

#### مراحل ورود گروهی
1. آرایه JSON بالا رو کپی کن
2. در تنظیمات → textarea JSON → Paste کن (کل محتوای قبلی رو پاک کن یا بهش اضافه کن)
3. دکمه **ذخیره JSON** رو بزن
4. اگر خطا داشت، زیر textarea خطا نشون داده می‌شه: مثلاً `هر آیتم date و title لازم دارد`
5. اگر موفق بود: `✅ ذخیره شد - 3 مناسبت` → برو تقویم، همه رو می‌بینی

#### نکات مهم
- تاریخ باید میلادی باشه، نه جلالی. تقویم اصلی میلادیه ولی روز جلالی کوچک زیر هر روز نشون داده می‌شه
- برای تکرار سالانه، فقط ماه و روز مقایسه می‌شه: `1990-08-30` و `2026-08-30` هر دو 30 اوت هستن → match
- رنگ‌ها از پالت Linear هستن: `#e4f222` لیمویی، `#6366f1` بنفش، `#02b8cc` فیروزه‌ای، `#eb5757` قرمز
- می‌تونی Export JSON بگیری تا بکاپ داشته باشی، بعد Import کنی

#### عیب‌یابی
- `Unexpected token` → کاما یا براکت جا افتاده، JSON باید معتبر باشه
- مناسبت نشون داده نمی‌شه → تاریخ رو چک کن `YYYY-MM-DD` باشه، نه `1405-06-08` (اون جلالی قدیمی بود)
- تکرار کار نمی‌کنه → `repeat` باید دقیقاً `"yearly"` باشه، نه `Yearly` یا `true`

## خلاصه
- کاربر عادی: فرم تقویم
- کاربر حرفه‌ای: تنظیمات → JSON textarea → Paste آرایه → ذخیره
